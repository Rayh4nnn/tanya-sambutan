# TanyaSambutan - UI/UX Prototype

TanyaSambutan adalah prototipe antarmuka asisten virtual berbasis web yang dirancang untuk menyimulasikan layanan informasi publik di tingkat Kecamatan Sambutan, Kota Samarinda. 

Proyek ini dikembangkan sebagai pemenuhan tugas mata kuliah Proyek Multimedia 1 di Program Studi D4 Teknik Informatika Multimedia, Politeknik Negeri Samarinda (POLNES).

> **Disclaimer:** Proyek ini murni merupakan prototipe akademik dan belum terhubung dengan sistem layanan resmi Pemerintah Kota Samarinda.

## Deskripsi Proyek
Fokus utama proyek ini adalah implementasi desain antarmuka pengguna (UI) yang bersih dan pengalaman pengguna (UX) yang intuitif untuk layanan informasi masyarakat. Prototipe ini menampilkan simulasi interaksi tanya-jawab terkait administrasi kependudukan (Dukcapil), informasi operasional, dan integrasi tautan ke layanan pengaduan resmi.

## Fitur Utama
* **Antarmuka Asisten Virtual:** Simulasi ruang obrolan dengan dukungan *quick reply chips* untuk akses cepat ke FAQ (contoh: persyaratan dokumen, estimasi biaya, dan waktu layanan) guna memenuhi kekurangan website resme kecamatan sambutan.
* **Panel Informasi Operasional:** Menampilkan jadwal operasional layanan secara dinamis.
* **Hubungi petugas :** bisa langsung hubungi petugas.
